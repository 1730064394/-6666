# Kali Command Center - GUI工具执行平台

## 🎯 概述

Kali Command Center 提供了一个强大的 **可视化图形界面（GUI）**，让你可以通过填写表单参数来执行Kali工具，无需记忆复杂的命令行参数。

## 🚀 快速开始

### 1. 启动服务

```bash
cd /workspace/kali-command-center
python3 app.py
```

### 2. 访问界面

服务启动后，浏览器访问：

- **GUI工具界面**: http://localhost:5000/gui （推荐！）
- **经典终端界面**: http://localhost:5000/

## 📊 GUI界面功能

### 2.1 工具选择系统

界面左侧显示分类的工具列表：

```
🔍 Information Gathering
   - Nmap (网络扫描)

🌐 Web Application Analysis
   - SQLMap (SQL注入)
   - Gobuster (目录扫描)
   - Nikto (Web漏洞扫描)

🔐 Password Attacks
   - Hydra (暴力破解)
   - John (密码破解)

📶 Wireless Attacks
   - Aircrack-ng (WiFi破解)

⚙️ System Utilities
   - Netcat (网络瑞士军刀)

🔧 Reverse Engineering
   - GDB (调试器)
```

### 2.2 参数表单系统

选择工具后，中间区域会显示自动生成的参数表单：

#### 示例：Nmap扫描

| 参数 | 类型 | 说明 |
|------|------|------|
| 目标 | 文本输入 | IP或域名（必填） |
| 扫描类型 | 下拉选择 | 版本检测、操作系统检测等 |
| 端口范围 | 文本输入 | 如：1-1000 |
| 额外选项 | 文本输入 | 其他Nmap选项 |
| 输出文件 | 文本输入 | 保存扫描结果 |

#### 示例：SQLMap注入测试

| 参数 | 类型 | 说明 |
|------|------|------|
| 目标URL | 文本输入 | 目标URL（必填） |
| 扫描级别 | 下拉选择 | Level 1-5 |
| 风险级别 | 下拉选择 | Risk 1-3 |
| 自动模式 | 复选框 | 自动回答问题 |
| 获取数据库 | 复选框 | 列出所有数据库 |

### 2.3 命令预览

表单下方实时显示构建好的命令：

```
$ nmap -sV -p 1-1000 192.168.1.1
```

### 2.4 终端输出

右侧面板显示命令执行结果：

- ✅ 彩色输出（成功/错误/警告）
- 📋 实时滚动
- 💾 复制/下载功能
- 🔄 清空输出

## 🎨 使用示例

### 示例1: Nmap快速扫描

1. 点击 **Information Gathering** 分类
2. 选择 **Nmap**
3. 填写目标IP：`192.168.1.1`
4. 选择扫描类型：`-sV` (版本检测)
5. 点击 **执行工具**
6. 查看实时输出

### 示例2: SQL注入测试

1. 点击 **Web Application Analysis** 分类
2. 选择 **SQLMap**
3. 填写目标URL：`http://target.com/?id=1`
4. 勾选 **自动模式**
5. 勾选 **获取数据库**
6. 点击 **执行工具**

### 示例3: SSH暴力破解

1. 点击 **Password Attacks** 分类
2. 选择 **Hydra**
3. 填写目标：`192.168.1.10`
4. 选择服务：`ssh`
5. 填写用户名：`admin`
6. 填写密码列表：`/usr/share/wordlists/rockyou.txt`
7. 点击 **执行工具**

## 🔧 功能特性

- ✅ **可视化参数配置** - 无需记忆命令参数
- ✅ **实时命令预览** - 随时查看生成的命令
- ✅ **分颜色输出** - 成功/错误/警告清晰区分
- ✅ **实时执行反馈** - 边执行边显示结果
- ✅ **快速命令** - 底部快速执行自定义命令
- ✅ **导出功能** - 复制或下载输出结果
- ✅ **响应式设计** - 适配不同屏幕尺寸
